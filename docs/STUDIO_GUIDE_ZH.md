# 工作台使用指南

TwinMarket Studio 是本地市场模拟研究工作台。当前版本只读，不启动模拟，不修改数据库、模型配置或外部数据源。

## 工作空间

| 空间 | 管理对象 |
| --- | --- |
| Experiment | 实验配置、运行、过程记录与结果 |
| Agent | 可复用的 Agent Group、成员画像与策略 |
| Market | 市场机制、资产包、行情与新闻快照、模拟环境 |
| Setting | 大语言模型、向量模型与金融数据源的全局连接 |
| Documentation | 已发布的项目文档 |

群体与环境由实验引用。未来创建实验时固定资源版本，历史运行不跟随全局默认配置变化。当前旧运行未记录独立资源版本，不应据此推断它使用了当前代码的全部规则。

## 实验监控

页面每 5 秒读取本地数据。顶部可以暂停自动读取、立即刷新，或切换舒适/紧凑密度。

- **近期有更新**：仅说明日志文件新鲜，不证明模拟进程存活。
- **日志未更新**：日志超过 120 秒没有变化，不直接判定失败。
- **已完成**：日志中发现模拟结束标记。
- **连接中断**：界面无法读取数据；运行页面保留上次快照，连接恢复后继续读取。

### 指标口径

| 指标 | 含义 |
| --- | --- |
| 参与 Agent | 运行数据库中的独立成员数 |
| 本次模拟交易 | 交易时间不早于实验开始日期的记录数；初始化历史另计 |
| 论坛帖子 | 论坛数据库中的帖子数；互动量在指标提示中查看 |
| 当前日对话 | 日志当前模拟日期目录下的对话文件数 |
| 日期快照 | 至少一个成员在该日期出现 Profiles 记录，不代表全部成员或当天流程完成 |

数据库、日志与文件是分别读取的，不是跨文件事务快照。并发写入时可能短暂出现不同的更新水位。

### 行情与结果

行情曲线使用收盘价，包含初始化历史；不是外部实时交易报价。数据缺少完整 OHLC 字段，因此不绘制 K 线。可切换资产或查看数据表。

结果产物只统计文件存在性，不将文件存在当作实验完成。当前尚未实现完整的收益归因、跨运行比较与社交图分析。

## Agent 与 Market

Agent 页面可搜索成员 ID、投资者类型或地区，并查看行为特征、持仓和策略。模板特征是输入标签，不是行为金融测试结论。

Market 页面展示当前本地环境、内置日级撮合机制、行业指数资产包与数据库存。资产包权重不等于某个 Agent 的持仓权重。行情、新闻和索引文件存在，不代表数据已验证完整或连接可用。

## 全局设置

当前只展示模型名称与配置存在性。**未测试**与在线状态不同；不会自动调用模型服务。数据源访问凭据归 Setting，拉取/更新任务归 Market。

## 后续功能

下列入口目前禁用，不执行操作：

1. 创建/编辑 Agent Group、保存群体版本与行为金融测试。
2. 创建市场机制、资产包、数据同步任务和环境快照。
3. 创建、启动、停止实验及配置有效模型绑定。
4. 模型/金融数据源凭据保存与主动连接测试。

后续资源工作流为：选择资源 → 配置参数 → 校验 → 发布版本 → 由实验引用。
