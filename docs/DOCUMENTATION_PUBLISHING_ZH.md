# 文档发布约定

Documentation 读取项目 `docs/` 目录（含子目录）中的 Markdown 文件。列表与正文接口都检查发布属性。没有发布标记的文件不会在模块中展示，也不能通过正文接口直接访问。

## 发布一篇文档

在文件最开头添加 YAML frontmatter：

```yaml
---
title: 我的文档
published: true
category: 使用指南
order: 30
---
```

| 属性 | 规则 |
| --- | --- |
| `published` | 必须为未加引号的布尔值 `true`；缺失、`false`、字符串 `"true"` 均不发布 |
| `title` | 可选；未填时取第一个一级标题，否则取文件名 |
| `category` | 可选；默认为“文档” |
| `order` | 可选整数；数值越小越靠前，默认 100 |

已有文档不会自动补发布标记。请在确认内容适合工作台读者后手动标记，尤其注意地址、凭据、内部记录等敏感信息。

## 同步与撤回

保存 MD 后，文档页每 5 秒重新检查列表和正文，也可手动刷新。设置 `published: false` 或删除该属性即可撤回。撤回后列表与直接正文访问均不再返回内容；已打开页面在下一次成功检查时清空正文。

模块只读取本地文档，不修改、复制或向外部服务上传文件。这里的“发布”只表示在当前本机工作台中可见，不代表互联网发布，也不是身份认证或权限系统。已交付给读者的文本或截图无法追溯撤销。

## 内容支持与安全边界

- 支持标题、列表、代码块、表格、引用与链接。
- 相对 `.md` 链接只跳转到已发布文档；未发布目标保持不可访问。
- HTML、脚本和事件属性不执行；代码示例仅作展示。
- 图片暂显示替代文本，不自动加载外部资源或任意本地文件。
- Mermaid 暂显示代码，不执行图表脚本。
- 路径限定在 `docs/`；不读取指向目录外部的符号链接。单文件最多 1 MiB，frontmatter 最多 16 KiB；损坏、重复键或无效发布属性默认不展示。

工作台操作说明见 [工作台使用指南](STUDIO_GUIDE_ZH.md)。
