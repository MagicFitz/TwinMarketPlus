## 比较与迭代记录

1. 首轮：完整框架参考与完整实验页均捕获并打开。发现 P2：日历最后一格孤立成行、辅助文字偏淡；桌面品牌字重偏重。
   - 修正：日历改为固定 8 列，手机 4 列；提升主要说明文字对比度与字号；导航/品牌降至 700 字重。
   - 复核：把框架参考和修正版实验页放入同一比较输入，确认奶油底色、自然绿、暖棕按钮与圆润字形协调；没有复制营销页插画到高密度研究页面。
2. 密度轮次：扩展紧凑模式，对页头、摘要、指标、日历、描述行与图表高度统一压缩；所有数据保留。相同 1440px 宽度下全页由 1549px 变为 1284px，减少约 17%。这是阅读密度对照，不是“所有内容都必须放进首屏”的承诺。
3. 手机轮次：P2：实验摘要内“查看配置”占据主行，日期被挤成多行。
   - 修正：摘要改为 40px / 自适应两列，配置入口独立放第二行。
   - 复核：重新运行全部浏览器检查并打开 `qa/experiment-390.png`，日期与成员信息正常换行，配置入口可见、可点，没有页面级横向溢出。
4. 最终局部对照：源按钮 155 × 49 与原型按钮 149 × 46 同时打开，检查暖棕文字、乳白底、胶囊圆角、底部阴影；差异来自文案长度和发布版本，符合使用真实框架组件的预期。

早期截图在本任务的工具输出中已检查；`qa/` 保存最终复核状态，固定文件名会被重跑脚本更新。

## 功能与数据验证

- Python：7 项测试通过，覆盖只读连接禁止 DELETE、路径越界、缺失数据库、配置白名单、日志拼接内容过滤、未知资源、快照日期不等于完成或连续覆盖。
- 浏览器：四路由与直接刷新、历史回退；分页、成员详情、Escape 关闭、空搜索；资产/曲线/数据表切换；规划入口；5 秒时间戳更新、暂停读取；断连保留旧值、手动恢复；1024/390 宽度页面无横向溢出。
- 前端交互过程中无 API 写入请求；专门的拒写测试 POST 返回 405。无 pageerror。断连测试中有预期的请求失败，不等同于代码异常。
- 数据未变化时保留对象引用，避免每次轮询无意义重建图表。换资源与取消请求时防止旧响应写回新页面。
- 焦点：抽屉限制 Tab 范围、Escape 关闭与关闭后恢复焦点；Tabs 支持方向键和 Home/End；按钮/搜索/选择器可键盘访问；减少动画偏好已处理。未执行屏幕阅读器全流程认证。
- `npm run build` 通过；模板打包测试 4 项通过。未部署到外部站点。

## 已知限制与后续

- P3：当前 JS 主包约 752 KB（gzip 250 KB），框架中文字体资源较大；产品化时拆分图表/路由并优化字体。当前验证是本机加载，不代表公网冷启动性能。
- 真实运行日志在验证期间未持续推进，因此验证了轮询、时间戳、读取暂停及故障恢复，未做活动模拟的长时间推进/高并发写入压力测试。
- 跨 SQLite/日志/文件的观测不是单个事务；晚到或部分日快照仍需未来结构化运行事件流解决。
- Group/Environment/Connector 注册表、写入 API、行为金融测试、完整结果分析保持规划状态。
- 仅本机无鉴权评估，不可直接公网暴露。分享前应制作脱敏静态版本或增加访问控制，并确认组件许可证适用范围。
